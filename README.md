# 803ETS
E听说答案图片分享网站，静态开源站点

## 项目介绍
纯静态网页，以**图片形式**汇总整理E听说各类习题答案，方便学生快速查阅学习。
无后端、无数据库，部署简单，支持GitHub Pages一键上线。

## 功能
- 图片展示全套E听说答案
- 关键词快速搜索答案
- 手机/电脑自适应浏览
- 轻量简洁，加载极速

## 使用方法
1. Fork 本项目
2. 将答案图片放入 `images` 文件夹
3. 在 `script.js` 内填写图片名称与标题
4. 开启 GitHub Pages 直接访问
